# 工业字段方案与资源占用

导入时先选择默认设备方案：通用、数控机床、旋转设备、压缩机、液压、热工或电气。方案推荐常用指标，用户仍可逐项决定是否用于预测。同一文件可按设备编号覆盖方案并选择自己的特征集合。

常见温度、振动、压力、流量、电流、电压、功率、转速、扭矩、运行时长、循环次数、位移、湿度、油位等可映射到标准指标。其他数值测点可保留为独立扩展指标，填写原单位，不会强行转成温度或振动。多测点同类传感器可分别保留。字符串备注可忽略或映射为设备状态、类型等辅助信息；不能将任意文本直接解释为数值传感器。

操作：上传CSV/XLSX → 选择方案及设备覆盖 → 核对映射、单位与预测启用项 → 完整文件校验 → 核对预览 → 确认提交。AI仍仅接收表头与第一条样例数据，不设人为文件大小上限。CSV支持逗号、分号、制表符和竖线；时间支持日期时间或明确标注单位的Unix秒/毫秒时间戳。时间戳统一为UTC存储；无时区日期保持原值。

同一方案和同一特征集合分别训练模型、隔离未来7天标签的时间边界，再做验证和测试。自定义数值特征进入真实模型输入，而非仅导入留存。没有足够标签或时间外正负样本时，显示证据不足；工况趋势不代表故障概率。实际故障标记用于生成未来窗口标签，未来结果和故障标签不得作为预测特征。推荐方案不等于已验证的行业模型。

数据版本保存字段来源、单位、设备方案和选定特征。设备占用时间轴在维护计划及设备详情中展示，蓝色为生产订单，橙色为维护工单。点击生产订单显示详情，点击维护工单直接处理。人员时间轴以工人为行，任务块显示工单、设备和时段，原拖动及重新审批流程保留。重叠安排分行，取消/回收站任务不作为有效维护占用；无有效起止时间的任务不伪造时间块。

验证使用隔离测试数据库，不替换当前操作者的数据。本次未执行浏览器视觉或真实拖拽验收。
