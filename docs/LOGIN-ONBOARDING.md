# 账号登录与首次使用教程

所有业务界面必须先登录。未登录不能读取业务API；系统不再提供默认匿名单人入口。

首次运行由服务所在电脑上的用户创建管理员。管理员在“个人中心 → 创建与管理账号”创建其他人员账号，按岗位分配设备总管、维修人员或只读权限。系统不预设通用管理员密码。

每个账号首次进入时显示五步教程：认识工作空间、设备与数据、风险提醒、岗位维修流程、开始使用。设备总管、维修人员和只读账号看到相应岗位说明。

- 确认本步内容后才能进入下一步；可返回查看已读内容。
- 每一步保存到后端SQLite的auth_onboarding表，绑定已登录user_id。
- 刷新、退出或换浏览器登录后，继续尚未完成的步骤。
- 完成后永久保留完成时间，不再自动展示；操作指南仍可在“帮助”查看。
- 另一账号有独立进度。用户停用、退出、登录及账号角色权限继续由后端保护。
- 静态发布页也不再绕过登录。纯静态托管无法提供真实账号服务，需使用本地服务版或连接受保护后端。

验证：226项后端回归通过（含新增4项登录/进度持久化检查），6项客户端检查通过，生产构建与文件摘要检查通过。真实浏览器在隔离账号库中验证首次入口、未完成不挂载业务页、第二步刷新续接、完成进入工作台、退出重登不再展示。没有替操作员实际业务库创建测试账号。

## 个人中心

点击侧栏头像、顶部账号按钮或手机菜单中的“个人中心”进入。可查询账号信息、修改自己的密码、退出，并检索相关待办。管理员、设备总管看到本角色共享的预警复核、需求排程、审批与验收队列；维修人员只显示分配给关联人员编号的执行工单；只读账号没有处理待办。待办可按类别筛选、按工单或设备搜索，并跳转到原有业务处理流程。

创建与管理账号仍限管理员。修改密码会撤销旧会话，需要重新登录。权限继续由后端校验，个人中心不放宽原有角色边界。
