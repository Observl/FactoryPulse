# SQL 数据库文件导入

在“数据中心 → 数据导入与模型验证”选择文件。企业监测数据统一走字段映射、单位核对、完整校验、预览和人工确认替换流程。

## 支持范围

- CSV / XLSX 监测表。
- SQLite 数据库文件：`.db`、`.sqlite`、`.sqlite3`。上传后先选表，再读取字段。
- UTF-8 编码、SQLite 兼容的 `.sql` 文件：支持普通建表、插入与事务语句。不会执行附加数据库、扩展加载、视图、触发器等可执行操作。
- 项目自己的 SQLite 业务库：选择 `records` 表时，仅提取 `table_name=readings` 的监测记录，不包含其他业务记录。

MySQL、SQL Server、PostgreSQL 连接串和专有备份文件尚未支持；可先导出监测表为 CSV。数据库文件上限100MB，单表最多200000行。超过限制时需按设备或时间分批导出。

## 数据保护

上传与分析不会替换当前业务数据。字段校验通过后，仍需勾选确认并提交，后台检查预览时的数据版本是否已变化。旧数据按原有版本机制归档。

数据库读取采用只读连接、表名白名单校验和标识符转义。账号表、登录会话和系统配置表不能导入；不会把上传数据库作为运行中的业务数据库，也不会恢复其中账号。整库灾难恢复请使用已有备份恢复流程。

## 页面状态

各异步卡片保留标题、统计区和表格框架，未得到结果的指标显示 `--`。错误提示仍显示在原区域，未知值不当成0。

设备目录显示最新档案/采样状态：绿=运行、橙=预警、红=故障、灰=未启动或停机。缺少状态时提示“状态未知”。这是历史数据状态展示，不等同于现场实时开机检测。
