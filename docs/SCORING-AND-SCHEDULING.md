# 评分解释与维护计算

设备详情中的规则、近期变化、模型和检查优先评分卡片均可点击，打开计算方式窗口。

- 规则：显示真实数据来源、输入、阈值、系数、分项贡献及重新计算结果。外部工作簿未提供公式时明确标注不可复算。
- EWMA：显示实际选用指标、α、样本数、当前值、平滑值、历史残差基线和趋势分。未修改原评分公式。
- 模型：保存完整 SHAP 原始分贡献和基准值，验证 `sigmoid(基准 + 全部贡献)` 与模型实际输出一致，再与四位小数的展示分核对。前几项贡献不能单独用于复原。
- 最终分：模型可用时使用模型分，否则采用趋势分，再否则使用来源规则分；不进行加权融合。评分未经概率校准，不能解释成真实故障概率。

唯一冻结软件验收集逐设备检查规则、EWMA、模型复算。仍不能据此证明现场预测有效或因果关系。

## 比较性能

方案比较在一次请求内共享设备快照、人员、订单和工单数据；联合选择前不再执行结果会被丢弃的预算预选。同一请求中，候选任务与所有约束完全相同的排程复用一次求解结果，不跨请求复用陈旧业务状态。

本机同一冻结数据、固定起算时间的一次对照：约30.6秒降为20.1秒，三种策略的任务数、优先级总分、预算耗用与工时一致。报告生成于 `outputs/comparison-performance.json`，不代表并发负载或所有输入的性能上限。

## 最早可行安排

联合求解仍同时检查设备窗口、人员技能与班次、人员工时、生产占用、现有工单、库存、预算和累计工时。选择目标优先维护优先级总分，其次缩短总完成时间；可行解不冒充已证明最优解。

未指定起算时间时，从当前时间向上取整到分钟开始，不把任务安排在已经过去的整点。秒级可用窗口起点向上取整，占用结束向上取整、窗口结束向下取整，避免分钟离散化侵入生产时间。没有空档或资源不足时报告冲突，不移除约束来制造安排。
