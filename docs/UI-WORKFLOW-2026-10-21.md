# 维护界面修复记录

## 本次变更

1. 操作表单统一互斥：工单审批、执行、撤回、恢复等操作切换时关闭另一份表单；有未保存内容时先确认。资源条件编辑和人工维护需求也互斥，密码修改与历史回放需求接入同一机制。
2. 取消及其他未分类操作按钮采用统一的白底描边样式，统一高度、圆角、焦点和禁用状态。
3. 工单处理记录采用纵向事件线，分开展示状态变化、操作时间、人员和说明；工单弹窗移除重复的处理过程区域。
4. 术语解释文字继承所在行字号、字重和颜色，避免风险计算卡片中的部分文字被错误放大；窄屏计算符号居中且不再旋转。
5. 切换历史数据版本保留排程条件控件，并明确只读；生成安排禁用并解释需先恢复数据。加载期间保留版本选项，避免选择器闪失。
6. 历史数据版本仅保留一层折叠。
7. 指标词典使用“精确率、召回率、F1分数、误报率”等简洁名称，解释与示例保留在展开内容中。
8. 修复弹窗双滚动条、创建时间紧贴标题，以及待审批工单流程定位错误。
