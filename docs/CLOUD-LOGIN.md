# 线上与本地登录

网站依据发布目标及域名自动选择登录入口。GitHub Pages（`observl.github.io`）和静态发布构建使用线上展示入口；本地服务版使用真实后端账号服务。后端连接失败不会切换成免密模式。

## 线上展示入口

- 只读访客：点击“只读用户 · 一键进入”，无需输入凭据。
- 管理员：显示名称“线上测试员”，账号 ID `test`。名称或 ID 均可登录；使用项目所有者指定的演示密码。
- 管理员可导出验收报告；访客只有查看功能。两种身份均可退出。刷新保留当前标签页会话，关闭标签页后不长期保存身份。
- 密码输入不存入浏览器。此版本为公开静态展示，前端身份可被修改，不构成真实的安全认证。真实账号、共享数据库、导入、排程和审批必须由后端提供；本页不会伪造这些操作成功。

## 本地服务入口

使用原有管理员初始化、独立账号登录、新手教程与服务端权限校验。线上演示身份不写入本地业务库，也不能代替本地登录。真实本地管理员账号不发布到 GitHub。

如需在线上执行完整业务并隔离真实用户数据，应另行部署后端与数据库，通过 HTTPS 同源代理提供 `/api`；GitHub Pages 本身不具备这一能力。
