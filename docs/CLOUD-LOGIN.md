# 统一账号登录

所有部署加载同一个完整工作台，账号、密码哈希、角色、会话和教程进度统一由服务端读写 Cloudflare D1。

使用从 10001 开始递增的用户编号登录，不再使用独立 username 字段。D1 直接保存开发者、管理员、普通用户、只读用户四类中文角色。完整规则见 [账号表规则](ACCOUNT-SCHEMA.md)。

只有显式指定并启用的只读访客账号提供一键入口。其他用户输入用户编号和本人设置的密码。没有浏览器模拟认证或默认密码。

GitHub Pages 仅能托管完整前端文件。真实登录和业务能力需要运行 Python 服务；部署说明见 [完整部署](CLOUD-DEPLOYMENT.md)。D1 令牌不进入浏览器或公开源码。
