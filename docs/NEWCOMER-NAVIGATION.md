# 新人操作布局

日常从工作台待办进入，点击即可处理具体预警或工单。常用入口保留设备查询、维修资源与上手指南。

维护中心的日常处理分为预警复核、工单处理、操作记录，分别展示对应内容。工单处理集中排程、设备及人员时间轴、审批、执行、验收与回收站。资源配置集中检修要求、人员班次、生产订单、预算限制和备件，移除重复工单与策略预览。

设备台账优先展示设备列表，风险排行可展开查看。风险中心优先展示设备风险，历史验证与回放收在独立展开项中。数据中心优先提供企业导入与质量检查，示例数据、完整工作簿和历史版本可展开查看。

每页提供使用指南。指南按准备数据、复核预警、核对资源、安排审批、执行维修、验收归档六步列出职责、操作入口及完成条件。指标含义、模型限制、备份范围仍保留在帮助中。审批假设、数据替换确认、库存耗用与未保存提醒等关键确认不删减。

本次是布局及文字优化，未修改后端预测、审批或排程算法。新人实际完成率和学习耗时仍需真实人员试用验证。
