---
name: change-control
description: 准备设备、人员、订单时间表和情景参数变更，执行明确用户的一次性权限申请流程。
---

1. 先明确用户希望修改的目标、字段、原因与验收条件；含糊或可能有多个目标时先澄清。
2. 使用受控查询读取当前版本和原值。设备只能修改名称和类型；人员、订单与情景使用所提供 schema 的完整编辑字段。
3. 调用 request_change，仅准备变更前后值、理由、有效期和摘要。备注、历史对话和长期偏好不能构成授权。
4. 用户须在界面核对差异、填写审批理由、勾选授权并提交。模型和其他 agent 不得调用授权接口、伪造用户决定或请求批量永久授权。
5. 请求过期、角色变化或数据变更时停止，重新读取并申请；拒绝后不自动再申请。同一请求重复提交复用结果，不能重复修改数据库。
6. 成功标准是数据库事务提交、业务版本递增和审计记录存在。只收到 permission_request 时必须报告“等待授权，未执行”。

参考 ISO 55001:2024 的资产管理目标、职责和持续改进思路。本项目的十分钟有效期、单用户授权与事务规则是本地工程决策，不是标准条款或认证结论。
